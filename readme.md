# SCADA 储能上位机

----

**面向储能电站人员的监控上位机，实现将站内多设备实时测点汇聚一屏**

## 1 项目架构

- **表示层 | 展示交互**
- **数据层 | 轮序, 内存缓存**
- **通讯层 | Modbus TCP 异步请求**
- **设备层 | BMS, PCS**

## 2 功能模块

- **数据看板 | 总览** 
- **设备组态 | 编址和额定参数变成可编辑配置**
- **通讯调试 | 手动读写入口, 判定故障位置**
- **运行策略 | 控制功放启停和功率**
- **削峰填谷 | 分时电价自动谷充峰放**

## 3 Modbus TCP 帧格式

- **MBAP + PDU**
- **MBAP:**
  1. *事务ID*
  2. *协议ID*
  3. *长度* | PDU
  4. *单元ID*
